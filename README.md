## 🛠️ Etapas do Trabalho

### 🔹 Passo 1: Estruturação do Grafo
Todos começam juntos definindo a estrutura de dados do grafo:
- **Lista de adjacência** (mais eficiente para grafos esparsos)
- **Matriz de adjacência** (mais simples, mas pode gastar mais memória)
- **Outra estrutura?** (Justificar no relatório)

### 🔹 Passo 2: Implementação do Algoritmo
Cada grupo desenvolve sua respectiva abordagem.

### 🔹 Passo 3: Testes e Comparação
- Criar casos de teste **pequenos, médios e grandes**
- Medir **tempo de execução** das abordagens
- Comparar desempenho e documentar observações

### 🔹 Passo 4: Relatório
Cada grupo documenta sua implementação e análise de desempenho.
- **Giuseppe e Caio** organizam o relatório final e garantem a formatação correta.
